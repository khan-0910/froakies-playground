# Froakie's Playground

A Pokémon card value tracker: every English and Japanese card, set by set, with TCGplayer and Cardmarket prices, and a flippable binder saved in your browser.

- `npm install` then `npm run dev` to work on it locally.
- Every push to `main` deploys to GitHub Pages.

Fan-made. Pokémon and card art © Nintendo, Creatures, Game Freak and The Pokémon Company. Data from TCGdex, pokemontcg.io and PokeAPI. Not affiliated.
